# Генератор персонажей

Курсовой проект на Python с использованием MySQL.

Программа предназначена для создания персонажей для настольных и компьютерных ролевых игр. Данные об играх, расах, классах, подклассах и предысториях хранятся в базе данных MySQL.

## Возможности программы

Пользователь может выбрать тип игры и конкретную игру, после чего доступны три способа создания персонажа:

1. **Ручное создание** — пользователь самостоятельно выбирает расу, класс, подкласс и предысторию.
2. **Тест** — пользователь отвечает на несколько вопросов, после чего программа подбирает подходящий класс персонажа.
3. **Случайная генерация** — параметры персонажа выбираются случайным образом из доступных для выбранной игры данных.

Созданному персонажу можно задать имя и сохранить его в базе данных.

Также программа позволяет просматривать ранее сохранённых персонажей.

### Основные файлы

**gui.py** — графический интерфейс программы.

**database.py** — подключение к MySQL и выполнение запросов к базе данных.

**generator.py** — логика ручного и случайного создания персонажей.

**quiz/** — система тестирования для подбора персонажа.

**main.py** — консольная версия программы.

## База данных

База данных хранит информацию об играх и параметрах персонажей.

Основные таблицы:

- `game_types` — типы игр;
- `games` — игры;
- `races` — расы;
- `classes` — классы;
- `subclasses` — подклассы;
- `backgrounds` — предыстории;
- `characters` — сохранённые персонажи.

Таблицы связаны между собой внешними ключами.

## Запуск проекта

### 1. Установить Python

Для работы программы необходим Python 3.

### 2. Установить MySQL Connector

В терминале выполнить:

```bash
pip install mysql-connector-python
```

### 3. Запустить MySQL

Перед запуском программы необходимо запустить MySQL-сервер.

В проекте для локального сервера используется Open Server Panel.

### 4. Настроить подключение к базе данных

Параметры подключения находятся в файле:

```text
src/database.py
```

Необходимо указать параметры своего MySQL-сервера:

```python
mysql.connector.connect(
    host="localhost",
    port=3306,
    user="root",
    password="ВАШ_ПАРОЛЬ",
    database="character_generator"
)
```

Параметры должны соответствовать настройкам локального MySQL-сервера.

### 5. Запустить программу

Основной графический интерфейс запускается файлом:

```text
src/gui.py
```

Из терминала:

```bash
python src/gui.py
```

После запуска откроется главное окно программы.

## Работа с программой

В главном меню доступны:

- **Создать персонажа** — перейти к генератору;
- **Мои персонажи** — посмотреть сохранённых персонажей;
- **Выход** — завершить работу программы.

При создании персонажа необходимо выбрать тип игры и игру.

После этого можно выбрать один из трёх режимов:

- составить персонажа вручную;
- пройти тест;
- создать случайного персонажа.

Полученного персонажа можно сохранить в базе данных.
