# Character Generator

Приложение для создания персонажей для настольных и компьютерных ролевых игр.

## Что делает программа

Приложение позволяет:

- выбрать настольную или компьютерную игру;
- выбрать конкретную ролевую игру;
- создать персонажа вручную;
- создать случайного персонажа;
- подобрать персонажа с помощью небольшого теста;
- выбрать расу, класс, подкласс и предысторию;
- задать имя персонажу;
- сохранить созданного персонажа;
- просмотреть ранее сохранённых персонажей.

## Режимы создания персонажа

В программе реализованы три режима:

1. **Ручное создание** — пользователь самостоятельно выбирает параметры персонажа.
2. **Тест** — программа задаёт несколько вопросов и подбирает класс на основе ответов.
3. **Случайная генерация** — параметры персонажа выбираются случайным образом.

Для Cyberpunk RED используется отдельный набор вопросов.

## База данных

В приложении используется база данных MySQL `character_generator`.

Основные таблицы:

- `game_types` — типы игр;
- `games` — игры;
- `races` — расы;
- `classes` — классы;
- `subclasses` — подклассы;
- `backgrounds` — предыстории;
- `characters` — сохранённые персонажи.

Данные связаны между собой внешними ключами.

Для работы с MySQL используется библиотека `mysql-connector-python`.

## Интерфейс

Графический интерфейс программы реализован с помощью Tkinter.

В программе имеются:

- главное меню;
- экран выбора игры;
- ручной режим создания;
- графический тест;
- случайная генерация;
- карточка созданного персонажа;
- список сохранённых персонажей.
